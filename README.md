## RoboMaster 机甲大师赛

RoboMaster（机甲大师）是由大疆创新（DJI）主办的机器人竞技赛事。高校战队自主研发多种机器人，以 7V7 的形式在赛场上进行射击对抗，比拼的不仅是机器人性能，更是队员在机械、电控、视觉与算法上的综合工程能力。

iROBOT 小队正是围绕这项赛事开展备赛与研发，在实战中打磨技术、以赛促学。

## 如何在 VS Code 中预览网页

### 方法一：使用 Live Server 插件（推荐，实时刷新）

1. 在 VS Code 左侧扩展栏搜索并安装 **Live Server**（作者 Ritwick Dey）。
2. 打开 `index.html`，右键选择 **「Open with Live Server」**。
3. 浏览器会自动打开 `http://127.0.0.1:5500/index.html`，修改代码保存后页面自动刷新。

### 方法二：直接打开文件

在文件资源管理器中双击 `index.html`，用浏览器直接打开即可（无需任何插件）。

### 方法三：使用命令行启动本地服务

```bash
# Python 3
python3 -m http.server 8000
# 或 Node.js
npx serve .
```

然后浏览器访问 `http://localhost:8000`。

## 技术要点

- **配色**：以蓝青渐变（`#2563eb → #06b6d4`）为主色，简洁、科技感。
- **动画**：页面加载淡入（`body` 的 `pageFade` + 首屏元素的 `fadeUp`），滚动到视口时卡片淡入显现。
- **交互**：导航栏滚动阴影、移动端汉堡菜单、返回顶部按钮、IntersectionObserver 滚动显现。
- **响应式**：桌面三列 / 平板两列 / 手机单列，适配不同屏幕。
